Framework

Vibekit — Things, Changes, States.

Maker Studio is powered by Vibekit. Build from the CLI, ship from the app, or mix both. It’s the event-driven heart of the Path.

Core pattern

Things Changes (Events) States

You model what exists (Things), what can happen (Changes), and what it results in (States). Maker Studio outputs the same files you’d craft by hand.

CLI workflow

Same toolchain, now with a studio UI.

The CLI you already know sits beneath the glass. The docs shipped with the repo still apply.

# Create a new site
vibekit new my-founder-home --template newsletter

# Run local preview
vibekit serve

# Publish to your configured target
vibekit publish
